# Euhedron

An independent software lab building systems for context, agency, and governance.

We build software that helps people and institutions turn their own information, feedback, and rules into systems they can understand, govern, and improve.

- **[commissure](https://commissure.ai)**: a local-first agentic context engine for your digital life. Your corpus is stored on your machine and grows more useful over time.
- **[arc](https://github.com/euhedron/arclite)**: agent-first code auditing that finds what tests and linters miss. Open source (MIT), and audited by itself on every push.
- **[crux](https://crux.euhedron.com)**: one engine for all of it. A public alpha you can download now; installed copies update themselves.
